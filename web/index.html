TransitFM1

A tiny firmware for the M-VAVE FM-1 to stop at between two others: every installer takes it for the official V15, and the write that replaces it is guarded until its last sector.

Before you start

0.1.1 replaces 0.1. 0.1 crashed on its first start after the official V15 (the FM-1 ended in its USB rescue, then in the chip's USB boot) and stopped listening to the installer while a DAW sent MIDI to the FM-1; 0.1.1 fixes both. If you installed 0.1 from ChoralRoot it works, but install 0.1.1 over it. Arriving from V15, a cut-off write ends in the chip's USB boot rather than update mode: have MvaveFM1Unbricker (Windows or Linux) or the FM-1 Transporter in mind. Close any app that sends MIDI to the FM-1 while you install. Installing firmware is at your own risk.

Install

Chrome or Edge on a computer; the FM-1 charged, switched on and connected with a USB data cable, directly. Released ….

    If an install is cut off
    
    
    From TransitFM1, a pulled cable or a flat battery is not the end: switch the FM-1 off and on.
      Three short flashes of the key lights and a black screen mean update mode. Open this page (or the installer
      you were using) and press Install again with the same firmware: it finishes the write. Holding OCT-
      while switching on gives the same update mode at any time.
    
    
    Do not switch off and on twice in a row while it is in update mode: the second time it drops into the
      chip's own USB boot ("WL82 UBOOT1.00"), where MvaveFM1Unbricker
      takes over (Windows or Linux).
    
  
    

  
    
    
    Leaving TransitFM1
    
    
    Install the next firmware with its own installer: it sees an FM-1 on the official V15. Whatever
      the package, TransitFM1 writes it with its own update loader, the new firmware's first sector last. To go back to
      stock, install M-VAVE's FM-1.fwsc.
    
    
    
      Install a package file from here
      
    An FM-1 package (.fwsc), for example M-VAVE's FM-1.fwsc or the release
        of the firmware you are going to. Also finishes a cut-off install of that file.
    
      
    
        
        
      
    
    
    
  
    

  
    
    
    How much of a write is guarded
    
    
    
      
    hopcut points with no rescue
    
      
    TransitFM1 → the official V15, or any firmware without ChoralRoot's stub16 of 2432: the last sector
    
      
    TransitFM1 ↔ ChoralRootnone
    
      
    the official V15 → TransitFM117 of 2432 (the first sector); the other cuts end in the chip's USB
        boot, not update mode (V15 stages the loader where the boot stub does not look)
    
    
    
    
    A power cut after every flash erase and every programmed page, judged by the boot stub's own code (host
      tests). How it works. Not from Bubba
      Machine: its updater accepts only M-VAVE's package; go back to V15 with its installer first.
